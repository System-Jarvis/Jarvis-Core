
# J.A.R.V.I.S. — Development Standards

## Overview

This document establishes the general development and documentation standards for the J.A.R.V.I.S. project.

These standards are intended to support consistent development practices, collaboration, project organization, and long-term maintainability.

## Version Control

J.A.R.V.I.S. development uses Git and GitHub for source control and collaboration.

Development practices include:

- Maintaining project work within the appropriate GitHub repository
- Creating dedicated branches for new features, documentation, and significant changes
- Writing clear and descriptive commit messages
- Reviewing changes before merging into the main branch
- Using pull requests to document and review proposed changes
- Preserving relevant development history

## Documentation Standards

Documentation practices include:

- Using Markdown for project documentation
- Organizing files into clearly defined categories
- Keeping documentation accurate and current
- Distinguishing planned features from implemented functionality
- Recording relevant technical decisions
- Updating documentation when significant changes occur
- Using clear and consistent terminology

## Security Practices

Development must prioritize secure and authorized system interactions.

Security practices include:

- Following least-privilege principles
- Protecting credentials, private keys, and sensitive information
- Avoiding the inclusion of secrets in Git repositories
- Obtaining authorization before accessing or modifying external systems
- Reviewing potentially destructive operations
- Maintaining appropriate logs and accountability
- Evaluating security implications of significant changes

## Development Progress

Development progress should be documented regularly.

Progress records may include:

- Completed tasks and milestones
- Current development activities
- Known issues and blockers
- Testing results
- Planned next steps

## Technical Decisions

Significant technical decisions should be recorded with:

- The problem or requirement being addressed
- The decision being considered or made
- Relevant alternatives
- Supporting rationale
- Known limitations or tradeoffs
- The current decision status
