
# J.A.R.V.I.S. — Project Overview

## Official Definition

**A self-hosted artificial intelligence platform.**

## Project Purpose

J.A.R.V.I.S. is an independent project focused on creating a self-hosted artificial intelligence platform.

The project is intended to bring together specialized AI agents, user interaction, automation, and connected computing systems within a unified environment.

## Project Objectives

The primary objectives are to:

- Develop a self-hosted artificial intelligence platform
- Incorporate multiple specialized AI agents with distinct responsibilities
- Enable users to communicate directly with individual agents
- Support collaboration and task coordination between agents
- Integrate with authorized computing devices and infrastructure
- Support automation and operational assistance

## J.A.R.V.I.S. Agent Network (J.A.N.)

The J.A.R.V.I.S. Agent Network (J.A.N.) consists of six planned AI agents:

| Agent | Primary Responsibility | Specialization |
|---|---|---|
| **J.A.R.V.I.S.** | Central Intelligence | Orchestration, General Assistance, Decision Support |
| **F.R.I.D.A.Y.** | Operations | Automation, Communication, Productivity |
| **E.D.I.T.H.** | Intelligence | Research, OSINT, Analysis |
| **U.L.T.R.O.N.** | Cybersecurity | Defensive Monitoring, Threat Modeling, Authorized Security Testing |
| **D.U.M.-E.** | Hardware | Diagnostics, Server Maintenance |
| **U.** | Terminal Management and Accessibility | File Management |

## Planned Capabilities

### Agent Presence

The proposed presence states are:

- **Available** — Ready to accept interactions
- **Working** — Processing assigned work
- **Idle** — Healthy but not actively engaged
- **Offline** — Unreachable or unable to report its operational state

### Terminal Interaction

Planned terminal capabilities include:

- Text-based agent conversations
- Agent selection
- Multi-agent conference interfaces
- Agent presence indicators
- Task monitoring

### Automation and Infrastructure

J.A.R.V.I.S. aims to support:

- Approved automation workflows.
- Infrastructure monitoring and diagnostics.
- Integration with authorized computers and servers.
- Hardware management assistance.
- Secure access to relevant platform services.
